# M6 Electrical contract (0.13.0, protocol 1)

`electrical.points.v1` exposes create_outlet, create_switch, create_electrical_point,
update_electrical_point, delete_electrical_point and validate_electrical.
`electrical.circuits.v1` exposes create/get/list/update/delete_circuit and
assign_to_circuit (also requires points capability). Read tools do not write metadata.

Points have root UUID, type electrical.outlet/switch/junction_box/connection_point,
schema_version=1, generated=true and revision=1 on creation. Geometry is a concept
box with explicit positive dimensions_mm.width_mm/height_mm/depth_mm. quantity=1..16
describes positions in one block; geometry is not multiplied. Name is a nonempty
string up to 128 characters; nullable sku up to 128; nullable description up to 1024.
Identity and type are immutable. Existing get_object/find/list/selection use the
shared entity serializer and generated-domain primitive guard.

Wall placement: mode=wall, wall_id, offset_mm/height_mm are the center U/Z anchor,
side=positive_v|negative_v, clearance_mm>=0 (default 0). Rear area must fit and be
fully supported on that Wall side for direct create/update. Projection subtracts
half width/height for WallAttachment spans; its lower-corner root frame flips X/Y
on negative_v. Geometry is X:0..width, Y:0..depth, Z:0..height. No Wall cuts.

World placement: mode=world, origin_mm is the rear-plane center, explicit normal/up
nonzero finite vectors. Up is projected perpendicular to normal and normalized;
parallel vectors are invalid. Y=normal, Z=corrected up, X=Y cross Z. Origin of
generated geometry is rear center minus half width along X and half height along Z.
All geometry public lengths are mm, all public axes are dimensionless.

Circuits are JSON UUID records in model HomeCAD.electrical_circuits_json (max 512),
type electrical.circuit, schema_version=1, generated=false, revision=1. Name required;
voltage_v optional positive; cable_label/protection_label/description optional text.
No automatic electrical sizing or compliance claim. Circuit targets require exactly
{homecad_id: UUID}; SketchUp identity fields are null. get_circuit derives member_ids;
list_circuits is bounded (limit 1..100, default 50; offset>=0).

Point circuit_id is the only membership source. assign_to_circuit requires circuit_id,
null detaches. Transfer increments point and old/new circuit revisions once. No-op
does not create Undo/revision. Deleting a used circuit requires detach_points=true,
which detaches mutable points atomically. Deleting a point updates its circuit.
Wall cascade deletion updates every affected circuit once; tombstones are captured
before erase. Every mutation uses one Operation; errors abort it.

Wall move/rotation relocates attachments, preserving local anchor/UUID; an effective
transform change increments point revision, not circuit revision. Fit violation
rejects Wall update. Architecture cuts may remove support: allow with bounded
missing_support warning; validate_electrical rediscovers it. Direct point updates
still require support. Structural loss never silently detaches a point.

validate_electrical(target=null, limit=50, offset=0) returns findings,total,limit,
offset,has_more. Categories: missing_support, missing_circuit, collision; severity
warning, point_id and obstacle_id (or circuit_id). Geometry conflicts use AABB then
full 3D OBB SAT (0.01 mm tolerance); touching is not intersection. Walls use occupied
cells, including side-specific niches. Furniture, Kitchen, Columns, neighboring
Walls and other ElectricalPoints are checked. Arbitrary SketchUp geometry is excluded.
Collision warnings never block mutations of another domain. Circuit labels are
project data, not manufacturer or regulatory verification.

Routes, panels, consumers, appliance matching, electrical loads, Lighting, normative
RU/EU rules and eval_ruby are outside M6. Dedicated smoke uses --confirm-disposable
and the exact HomeCADDev fixture; acceptance uses dev_verify --milestone m6 --packaged.
