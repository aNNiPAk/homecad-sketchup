# M1 scene contract

M1 methods are JSON-RPC methods sent after M0's protocol-version-1 `hello`. The response advertises the capabilities implemented by the loaded bridge. Every request has `params` as an object. The same names are MCP tools.

Current capability mapping: `model.info.v1` → `get_model_info`; `scene.inspect.v1` → `list_objects`, `find_objects`, `get_object`, `get_selection`; `scene.measure.v1` → `measure`; `view.capture.v1` → `capture_view`; `scene.undo.v1` → `undo`. `homecad_status` is the baseline status operation and has no required capability.

- `list_objects({context:'root'|'active', parent?, entity_type?, include_hidden:false, include_generated:false, limit:50, offset:0})` returns `{objects:[summary], total, limit, offset, has_more}`. A parent selector lists immediate children. Face/Edge are included only with an explicit `entity_type`.
- `find_objects({homecad_id?, persistent_id?, entity_id?, entity_type?, homecad_type?, name?, tag?, parent_id?, room_id?, metadata?, limit:50, offset:0})` returns `{resolution, objects:[summary], total, limit, offset, has_more}`. `name` is a case-insensitive substring; other predicates are exact. `room_id` matches existing HomeCAD metadata. At least one predicate is required.
- `get_object({target:{homecad_id?|persistent_id?|entity_id?, instance_path?}})` returns a detailed serialized object. An identity selector must resolve to exactly one scene placement.
- `get_selection({limit:50, offset:0})` returns `{objects:[standard], total, limit, offset, has_more}`.
- `measure({kind:'bounds'|'bbox_dimensions'|'center_distance'|'bbox_distance'|'face_area'|'edge_length', target?, other_target?})` returns `{kind, targets:[identity], unit, value}`. Bounds and bbox dimensions use a `bbox_mm` or `bbox_dimensions_mm` object as `value`; distance uses millimeters, face area uses square millimeters.
- `capture_view({view:'current'|'top'|'front'|'back'|'left'|'right'|'iso', zoom_extents:false, target?, max_size:1024, restore_camera:true})` returns a PNG image block to MCP plus capture metadata including `camera_before`, `camera_after`, and `camera_restored`. A target frames the resolved placement's world bounds.
- `camera_restored` compares the original camera state with the state after restoring an independent camera snapshot, including perspective FOV orientation (`fov_is_height`). A camera in two-point perspective is rejected when capture would change it and `restore_camera=true`. If the Ruby API cannot reproduce a perspective camera's FOV orientation, changing capture is rejected before the camera is modified.
- `undo({})` returns `{status:'queued', actions:1, operation:'undo'}` if SketchUp accepted one `editUndo:` action.

Shared `identity`: `{homecad_id, persistent_id, entity_id, instance_path}`. The first field is `null` for ordinary SketchUp objects. `instance_path` is an array of persistent IDs, falling back to entity IDs when a persistent ID is unavailable. The serializer's `summary` fields are included unchanged in `standard` and `detailed` outputs.

`summary` also repeats the three identifier fields at top level for convenient inspection. `standard` adds validity, visibility, tag/material, world-aligned bounds and `bbox_dimensions_mm` in mm, and parent/context. These dimensions describe the world-aligned axis-aligned bounding box and can differ from an object's local or parametric dimensions when it is rotated. `measure(kind:'bbox_dimensions')` returns the same values. No local or parametric dimensions are inferred for generic SketchUp entities. `detailed` adds existing HomeCAD metadata, world transformation, and one-level child counts. No child entities are recursively serialized.

The `dimensions_mm` field and `measure(kind:'dimensions')` from the initial M1 implementation were renamed before 1.0 because they implied parametric dimensions. Use `bbox_dimensions_mm` and `bbox_dimensions`.

Bridge errors retain M0's JSON-RPC envelope and `data.category`. M1 adds `target_not_found`, `ambiguous_target`, `constraint_violation`, and `geometry_error`. A missing method capability maps to `unsupported_operation`; malformed advertised capabilities map to `invalid_response`. Invalid parameters use JSON-RPC code `-32602`.

MCP tools `homecad_status`, `get_model_info`, `list_objects`, `find_objects`, `get_object`, `get_selection`, `measure`, and `capture_view` advertise `readOnlyHint=true`, `openWorldHint=false`. `undo` advertises `readOnlyHint=false`, `destructiveHint=true`, `idempotentHint=false`, `openWorldHint=false`.
