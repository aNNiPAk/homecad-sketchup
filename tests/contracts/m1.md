# M1 scene contract

All seven methods are JSON-RPC methods sent after M0's unchanged `hello`. Every request has `params` as an object. The same names are MCP tools.

- `list_objects({context:'root'|'active', parent?, entity_type?, include_hidden:false, include_generated:false, limit:50, offset:0})` returns `{objects:[summary], total, limit, offset, has_more}`. A parent selector lists immediate children. Face/Edge are included only with an explicit `entity_type`.
- `find_objects({homecad_id?, persistent_id?, entity_id?, entity_type?, homecad_type?, name?, tag?, parent_id?, room_id?, metadata?, limit:50, offset:0})` returns `{resolution, objects:[summary], total, limit, offset, has_more}`. `name` is a case-insensitive substring; other predicates are exact. `room_id` matches existing HomeCAD metadata. At least one predicate is required.
- `get_object({target:{homecad_id?|persistent_id?|entity_id?, instance_path?}})` returns a detailed serialized object. An identity selector must resolve to exactly one scene placement.
- `get_selection({limit:50, offset:0})` returns `{objects:[standard], total, limit, offset, has_more}`.
- `measure({kind:'bounds'|'dimensions'|'center_distance'|'bbox_distance'|'face_area'|'edge_length', target?, other_target?})` returns `{kind, targets:[identity], unit, value}`. Bounds and dimensions use a `bbox_mm` or `dimensions_mm` object as `value`; distance uses millimeters, face area uses square millimeters.
- `capture_view({view:'current'|'top'|'front'|'back'|'left'|'right'|'iso', zoom_extents:false, target?, max_size:1024, restore_camera:true})` returns a PNG image block to MCP plus capture metadata including `camera_before`, `camera_after`, and `camera_restored`. A target zooms to the resolved entity.
- `undo({})` returns `{status:'queued', actions:1, operation:'undo'}` if SketchUp accepted one `editUndo:` action.

Shared `identity`: `{homecad_id, persistent_id, entity_id, instance_path}`. The first field is `null` for ordinary SketchUp objects. `instance_path` is an array of persistent IDs, falling back to entity IDs when a persistent ID is unavailable. The serializer's `summary` fields are included unchanged in `standard` and `detailed` outputs.

`summary` also repeats the three identifier fields at top level for convenient inspection. `standard` adds validity, visibility, tag/material, world-aligned bounds/dimensions in mm, and parent/context. `detailed` adds existing HomeCAD metadata, world transformation, and one-level child counts. No child entities are recursively serialized.

Bridge errors retain M0's JSON-RPC envelope and `data.category`. M1 adds `target_not_found`, `ambiguous_target`, `constraint_violation`, and `geometry_error`. Invalid parameters use JSON-RPC code `-32602`.
