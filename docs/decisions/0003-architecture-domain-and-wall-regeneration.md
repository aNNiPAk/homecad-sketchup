# ADR 0003: Parametric architecture objects and wall regeneration

- Status: accepted for M3
- Date: 2026-09-25

## Context

HomeCAD needs architecture objects whose meaning and editable state survive wall movement and future attachment domains. SketchUp Solid Tools availability/boolean semantics are a poor dependency for routine wall cuts, and primitive face editing must not silently desynchronize domain data.

## Decision

Architecture objects are generated from validated parameters stored with HomeCAD metadata. Walls stay as root-level managed Groups and retain their root identity during updates. A shared wall-local frame uses start as origin, U along the horizontal baseline, global +Z, and V = Z × U. Hosted cut anchors remain wall-local when the wall moves or rotates.

Wall shell geometry is deterministically regenerated by partitioning wall-local U/V/Z at rectangular hosted-cut boundaries and emitting only exposed cell faces. Through cuts remove the full V span; niches remove only their selected side depth. The generator has a fixed hosted-cut and niche limit and rejects overlapping rectangles. It uses normal `Sketchup::Entities` geometry creation inside one HomeCAD operation and does not require Solid Tools.

Rooms preserve caller-ordered wall IDs. Their editable source of truth is the Room name and ordered wall IDs. Boundary coordinates, room-facing sides, approximate area, wall-side relationships, and generated reference geometry are derived together from current wall geometry whenever a Room or boundary Wall changes. Their local-facing side is computed from boundary winding and wall U direction. Room detection only reports simple snapped endpoint cycles, is read-only, and warns instead of guessing through ambiguous topology. The SketchUp Model remains the project root; no Apartment Group is introduced.

Nested architecture parameters and relationships use canonical JSON strings in the existing HomeCAD AttributeDictionary. Base identity/type/schema/revision/generated fields are unchanged. Wall relationships retain a separate searchable `wall_id` value.

## Consequences

- Wall updates preserve the root HomeCAD UUID while regenerating internal faces and affected hosted representations.
- A cut or Room that no longer fits causes a pre-operation `constraint_violation`; offsets are never clamped.
- Geometry generation is portable across SketchUp versions with standard Entities APIs and can be tested without Pro Solid Tools.
- Standalone tests do not prove SketchUp kernel manifoldness. Real SketchUp smoke must verify cut topology, Room reference faces, regeneration, and Undo behavior.
- Domain mutations remain one native Undo operation each; tombstones are serialized before deletion.
